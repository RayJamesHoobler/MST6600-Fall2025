# MST 6600

This repository was created for the Fall 2025 session, but will be
updated for the Fall 2026 session.

## Description (from the course syllabus)

Students will apply graphical exploratory data analysis techniques
(including: scatter plots, box plots, histograms, probability plots,
residual plots, and mean plots) to representative data sets using the
RStudio platform. Students will evaluate data using standard,
quantitative statistical techniques. Practical exercises and industry
cases are used throughout the term. Prior knowledge of R is not
required, but some programming experience will be helpful. Students are
expected to bring laptops to class. This is a required cohort class for
first-year Professional Science Master’s students and fulfills a
requirement of the Graduate Certificate in STEM Leadership and
Management; students from other graduate programs in STEM are welcome.
